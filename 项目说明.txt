项目：e621 搜索页视频导航
版本：1.8.1

目录
extension\：浏览器扩展源码。Chrome / Edge “加载已解压的扩展程序”请选择此目录。
verify-extension.cjs：浏览器回归测试。
fixtures\2x2-green.webm：Web Platform Tests 的绿色视频测试素材。
fixtures\test-1s.webm：Web Platform Tests 的 1 秒视频测试素材，供进度及全屏测试使用。
e621-next-video.zip：只包含扩展安装文件的分发包。

从旧路径升级
如果安装目录已移动，请移除从旧路径加载的扩展，再选择新目录中的 extension 文件夹。
刷新 e621 搜索结果页，然后重新点击视频。默认快捷键 ]。

全屏功能
在视频全屏时按 ]，获取来源队列中的下一个帖子并在当前播放器内切换视频。
保留全屏状态和音量、静音及速度设置，尝试开始播放；循环由播放结束模式决定。
退出全屏时打开当前视频的真实详情页，保证标签和评论与视频对应。

百分比快进
默认按 → 从当前位置快进总时长的 20%，普通及全屏播放均可使用。
插件弹窗支持设置按键及百分比（0 < 百分比 <= 100），并检查四个功能的按键冲突。
暂停状态保持暂停；超过结尾时限制到总时长。修改设置即时生效。
首次启用一键更新时手动重载一次；以后覆盖同一路径的文件，在高级设置点击“应用本地更新”，无需卸载重装。

双向导航与后退（v1.3.0）
默认 ] 下一个视频、[ 上一个视频、→ 快进 20%、← 后退 20%。
四项快捷键独立配置，快进与后退百分比独立配置，所有按键互相检查冲突。
视频导航遵循来源搜索页的队列，队列首尾停止；进度限制在 0 到总时长之间。
全屏支持双向切换；退出时同步到当前视频详情页。
旧默认 N 一次性迁移到 ]，其他自定义设置保持不变。

播放结束模式（v1.4.0）
新增 endMode 设置：loop（默认）或 next，可在弹窗选择并即时生效。
loop 开启媒体元素循环；next 关闭循环并监听 ended，共用手动导航逻辑。
普通自动跳转通过临时 URL 片段标记在目标详情页尝试播放，初始化后移除该标记。
全屏自动跳转保留播放器和全屏状态；页末及缺少队列时停止并提示。
切回循环模式会取消尚未完成的自动全屏请求。重复 ended 和手动导航共用切换锁。
已用实际浏览器播放测试视频验证循环、普通及全屏自动队列、失败重试和页末停止。

中英文界面（v1.5.0）
extension\i18n.js 提供中英文文案，供弹窗和 content script 共用。
language 设置为 zh（默认）或 en，存入 chrome.storage.local。
弹窗更新页面 lang、标题、标签、按钮、选项、按键名及校验提示。
网页提示保留消息键与参数，语言变化时立即重新渲染，无需改变其他播放设置。
已验证双向切换、持久保存、既有提示及新页面提示语言、文案完整性和英文弹窗宽度。

自动翻页（v1.6.0）
原生 details / summary 实现三角展开的高级设置抽屉，autoPage 默认 false。
在自动下一条模式的队列末尾读取记录中的 nextPage，沿用 e621 的 paginator-next 链接。
保留搜索参数，支持数字页码和 b/a 游标；旧记录按原来源页补齐分页链接。
用临时后台标签页加载下一搜索页，等待 blacklisted-hider 初始化标记消失后记录可见视频，再关闭临时页。
去除已记录的重复视频，将新视频追加到独立队列，保存新 token，避免修改其他标签页的原队列。
全屏成功切换后才提交当前队列，退出时同步真实详情 URL；普通模式用同一队列打开下一条并尝试播放。
设置改变和退出全屏支持取消请求；搜索末尾、空视频页、登录或加载失败时停止。
使用模拟搜索结果与真实浏览器视频播放测试，不访问 e621 实际视频。

翻页加载修复（v1.6.1）
e621 官方 CSP 设置 frame_ancestors :none，frame_src 只允许验证码站点，因此同源 iframe 也不能加载搜索页。
新增 background.js 服务工作线程，通过 chrome.tabs 创建不激活的临时标签页，内容脚本读取网站处理后的实际视频队列。
完成、失败、取消、关闭来源标签页或超时都会清理插件创建的临时标签页；不关闭用户已有标签页。
只使用已有 storage 权限；创建及关闭标签页不需要申请 tabs 权限。
错误提示区分搜索结果不可用、网站黑名单初始化超时、加载超时和插件后台连接失败。
回归测试执行实际 background.js，通过 Tabs API 测试桥连接浏览器页面，覆盖禁止 iframe 的 CSP、全屏跨页、过滤、失败重试和取消。
仍未在用户登录后的 e621 页面进行完整验证。
官方策略来源：https://github.com/e621ng/e621ng/blob/master/config/initializers/content_security_policy.rb

测试
在安装了 Playwright 的 Node.js 环境执行 verify-extension.cjs。
测试脚本默认使用 Node.js 环境安装的 Playwright，也可用 PLAYWRIGHT_MODULE_PATH 指定模块路径。
浏览器测试使用本机安装的 Chrome 和 Edge；在其他电脑运行时可能需要调整浏览器路径。
测试模拟页面数据，使用真实浏览器全屏和媒体播放 API；没有访问站点视频。

设置界面整理（v1.7.0）
四个快捷键以两列排列，去除各项独立重置按钮，只保留统一“重置快捷键与进度”。
统一保存六项默认值，避免逐项恢复时与现有自定义键冲突；保留语言、播放模式和自动翻页。
底部高级设置默认折叠，包含两个百分比输入、自动翻页和安装提示。
已验证中英文布局、默认折叠、百分比保存、按键冲突和一次重置后的持久保存。

手动跨页（v1.7.1）
autoPage 启用后，手动下一个视频也可在队列末尾调用下一页加载流程，循环模式同样生效。
分别跟踪自动翻页与手动翻页，播放模式及其他偏好变化不会意外取消手动操作；关闭 autoPage 则取消两者。
普通模式跨页后尝试播放，全屏模式保持当前播放器；沿用原有搜索参数、过滤和去重。
增加普通/全屏手动跨页、循环模式、非相关设置变化和手动加载取消的浏览器回归测试。

收藏列表支持（v1.7.2）
manifest.content_scripts 增加 https://e621.net/favorites*，列表入口及后台队列读取同时接受 /posts 和 /favorites。
pageIdentity 保留列表路径，nextPage 拒绝跨列表类型的分页链接，避免把收藏顺序替换成 fav: 查询的帖子顺序。
收藏页复用官方共享的 #posts .posts-container / article.thumbnail 结构；继续保留 user_id、limit 等原查询参数。
测试覆盖收藏页队列注入配置、首条结束后的自动播放、全屏连播跨页、黑名单处理和指定用户的手动翻页。

一键本地更新（v1.8.0）
仅接受同一扩展 popup.html 发出的更新消息；新增 e621 站点权限用于查询相关页面，不请求读取全部网站的 tabs 权限。
更新前取消并清理后台翻页任务，包括尚未返回的 tabs.create；保存短期一次性页面 ID/URL，再调用 runtime.reload。
新版本监听 onInstalled(update)，消费本地交接记录后刷新仍停留在原页面的搜索、收藏和视频页。
不会刷新已跳转到其他页面的标签页，不改语言/按键/模式；交接记录两分钟过期，普通启动不刷新。
使用 storage.local 而非 session，因为浏览器重载扩展时会清空 storage.session。
verify-update.cjs 验证来源校验、设置保持、过期/重复交接、标签关闭或跳转及加载页创建延迟，并运行真实 Edge/Chromium 扩展重载测试。
一键更新只应用已经覆盖到本地扩展目录的文件，不提供在线下载或自动解压。
