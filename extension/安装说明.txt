e621 搜索页视频导航 v1.8.1（Chrome / Edge）

安装
1. 把 ZIP 解压到一个固定文件夹。安装后请保留这个文件夹。
2. Chrome 地址栏打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压后含有 manifest.json 的文件夹；从源码安装时请选择仓库里的 extension 文件夹。
5. 刷新已打开的 e621 搜索结果页或收藏列表页。

使用
打开 https://e621.net/posts?page=5&tags=sound+order%3Afavcount
从该页点击一个视频，进入详情页后按 ]。也支持从 https://e621.net/favorites 收藏列表进入。
插件打开的是该页排列中紧接着的下一个可见视频。
重复按键可继续前进；开启高级设置中的“自动翻页”后，在第 5 页最后一个视频按 ] 可进入第 6 页的第一个可见视频。
图片和 GIF 不在视频队列中，被网页隐藏的结果也会跳过。
插件记住打开视频时搜索页中已显示的视频顺序，不随收藏数后续变化重新排序。

自定义按键
点击浏览器工具栏里的扩展图标（可先在拼图菜单中固定）。
点击“快捷键”输入框，按 ] 或所需组合键即可保存。
网页输入框、评论框、搜索框内不会触发导航。
快捷键需要网页获得键盘焦点；地址栏及浏览器保留快捷键无法被插件接管。

双向操作（v1.3.0）
]：来源搜索页中的下一个视频。
[：来源搜索页中的上一个视频。
→：从当前位置快进总时长的 20%。
←：从当前位置后退总时长的 20%。
四个快捷键均可在插件弹窗中修改；快进和后退的百分比可以分别设置。
普通模式和全屏模式都支持；未启用自动翻页时在来源页首尾停止，在视频开头或结尾不越界。
旧版默认键 N 会在升级时自动改为 ]；其他已保存的自定义键保持原设置。
迁移完成后也可以自行把任意不冲突的功能重新设置为 N。

播放结束模式（v1.4.0）
点击插件弹窗顶部“播放结束后”下拉框，选择以下模式：
1. 循环重播当前视频（默认）：结束后重新播放当前视频。
2. 自动播放下一条：结束后按来源搜索页的视频队列前进，等效手动按下“下一个视频”快捷键。
修改立即保存并对已打开的详情页生效，不改变自定义快捷键或百分比。
普通模式会打开下一条详情页并尝试开始播放；全屏模式在当前播放器内切换并保持全屏。
自动下一条会关闭循环；未启用自动翻页时到来源搜索页最后一条后停止，不回到第一条。
请先从已刷新过的搜索页进入视频，以便插件知道队列；直接打开且没有来源的视频会在结束时提示。
下一条加载失败时停止，可按 ] 手动重试；浏览器若阻止自动播放，请点击播放按钮。

中英文界面（v1.5.0）
插件弹窗最上方新增“语言 / Language”，可选择“简体中文”或“English”。
未选择语言时默认 English。手动选择后立即保存，升级后仍保留所选语言。
弹窗的标签、按钮、播放模式、帮助和错误提示，以及网页中的插件提示会一起切换。
已打开网页上的提示也会即时换语言，不会修改快捷键、快进后退比例或播放结束模式。
升级到本版本后仍需在扩展管理页重新加载插件并刷新 e621 网页，让新脚本生效。

高级设置和自动翻页（v1.6.0）
点击插件弹窗中的三角符号或“高级设置 / Advanced settings”展开抽屉。
勾选“自动翻页 / Automatic pagination”，并把“播放结束后”设为“自动播放下一条”。
当前搜索页最后一个视频播放结束后，自动接着播放下一页的第一个可见视频。
继续使用原搜索词、排序和每页数量，支持网站的数字页码和游标分页。
全屏时保持当前播放器和全屏，退出全屏时打开当前视频的正确详情页。
跨页后的队列会保留此前视频，所以 [ 仍可回到上一页播放过的视频。
自动翻页默认关闭；开启后，手动 ] 在页尾也会继续下一页，不要求选择“自动播放下一条”模式。
到搜索结果最后一页，或下一页没有可见且未播放的视频时停止。
下一页会在临时后台标签页中加载，以让网站应用当前账号的黑名单设置；读取后自动关闭该临时页。
临时页不会自动切换到前台，全屏视频会继续保留在当前播放器中。
如果加载失败或需要登录，会停止并提示；重新播放当前视频结束后可以再次尝试。
加载中关闭自动翻页会取消翻页请求；切换为循环模式只取消由播放结束触发的自动翻页，手动翻页可继续。
测试覆盖模拟网站的黑名单初始化、普通及全屏跨多页、参数保留、失败重试和取消；实站仍需验证。

自动翻页修复（v1.6.1）
修复旧版使用 iframe 加载下一页，被 e621 安全策略阻止而出现“下一页加载失败”的问题。
改用临时后台标签页，不增加扩展权限；加载成功、失败、取消或超时后关闭临时页。
失败提示会显示具体原因。网站要求验证或登录时，请先在普通搜索页完成后再重试。
升级步骤：在扩展管理页点击本插件卡片的“重新加载”，再刷新 e621 搜索页并重新进入视频。

按百分比快进
在视频详情页按右方向键 →，默认从当前位置快进总时长的 20%。全屏时也能使用。
例如视频总长 100 秒，目前在 30 秒，按一次会跳到 50 秒。
点击插件弹窗里的“快进快捷键”可以修改按键；百分比在底部“高级设置”中，修改后离开输入框即保存。
百分比必须大于 0、不超过 100，可输入小数。超过视频结尾时停在结尾。
快进会保留当前播放或暂停状态；长按不会连续触发。
“下一个视频”“上一个视频”“快进”“后退”的快捷键不能互相重复。
此功能也支持直接打开的视频详情页，不需要先记录搜索页顺序。

注意
每个搜索页都有独立队列，可同时打开多个搜索页。
支持普通点击、Ctrl 点击和中键打开新标签页。
扩展会在链接末尾加 #e6nav=...，用于关联来源页；这是正常现象。
直接打开不带这个标记的视频链接时，插件不会猜测来源页。
从搜索页刚加载完成就立刻点击，记录可能尚未就绪；此时返回刷新后再点击。
旧记录最多保留 7 天和最近 200 个队列；清理后需要重新从搜索页打开。
全屏播放
视频全屏时也可以按 ]：在同一个播放器内切换下一个视频并尝试播放，保持全屏。
可连续按 ]；音量、静音和播放速度沿用当前播放器设置，循环由所选播放结束模式控制。
退出全屏后会打开当前正在播放的视频详情页，更新标签、评论等内容。
全屏连续播放期间地址栏仍是进入全屏前的帖子；分享链接请先退出全屏。
加载失败时不会跳过该视频，可再次按 ] 重试。
若浏览器阻止播放，请点击播放器的播放按钮。
普通非全屏导航仍通过打开详情页实现，自动播放由网站和浏览器决定。

升级旧版
如果原来的扩展路径已被移动，先在扩展管理页移除旧扩展，再加载上述 G 盘文件夹。
扩展从新路径加载后，请刷新搜索页并重新从该页打开视频。
首次升级到 v1.8.0 时，请在扩展管理页重新加载一次，使一键更新功能生效。
以后同一路径更新代码，先覆盖文件，再打开插件的“高级设置”，点击“应用本地更新”。
插件会自动重载，并刷新已打开的 e621 搜索、收藏和视频页面；当前播放会中断，设置保留。
无需再逐个手动刷新网页；浏览器其他网站不会刷新。本地更新按钮不会联网下载新版。

权限和数据
页面脚本只在 https://e621.net/posts* 和 https://e621.net/favorites* 页面运行。
使用扩展本地存储，以及 https://e621.net/* 的站点权限；站点权限用于识别更新时需要刷新的 e621 标签页。
记录来源 URL、视频链接及快捷键，保存在本机浏览器扩展存储中。
没有远程服务器、账号/API Key 配置或视频下载功能。

验证范围
已按 e621 开源源码确认新旧缩略图选择器，并用模拟页面验证核心流程。
已用浏览器真实全屏 API 和 WPT 绿色测试视频验证全屏连续切换、播放、重试和退出同步。
已用 WPT 视频验证普通及全屏百分比快进、结尾限制、暂停保持和自定义设置。
未在已登录的 e621 实际页面进行完整实机验证。

设置界面整理（v1.7.0）
主界面用两列显示四个快捷键，只保留一个“重置快捷键与进度”按钮。
重置一次恢复 ]、[、→、← 及两个 20%；语言、播放结束模式和自动翻页设置保持原值。
“高级设置”移到最底部，默认折叠，包含快进/后退百分比、自动翻页及安装提示。
设置仍会自动保存，中英文界面同步调整。更新后在扩展管理页重新加载插件并重新打开弹窗。

手动跨页（v1.7.1）
开启“自动翻页”后，页末手动按下一个视频快捷键也会播放下一页的第一个可见视频。
循环重播模式下也支持手动跨页，全屏时保持全屏；[ 可以回到已加载的上一页视频。
关闭自动翻页时仍会在队列末尾停止，并提示在高级设置中开启该功能。

收藏列表支持（v1.7.2）
修复独立收藏列表 /favorites 未加载插件、无法记录队列导致不能连播的问题。
支持自己的收藏列表，以及 /favorites?user_id=... 指定用户的公开收藏列表。
按收藏列表实际显示顺序跳过图片与隐藏内容；自动下一条、手动前后切换及普通/全屏翻页均可使用。
收藏列表与 /posts?tags=fav:username 搜索分别记录队列，翻页保留原列表路径、用户及每页数量。
升级后重新加载插件，刷新收藏列表，再从该列表重新进入视频；播放结束模式请选择“自动播放下一条”。

一键应用本地更新（v1.8.0）
高级设置底部新增当前已加载版本号及“应用本地更新”按钮，中英文同步支持。
更新时会先关闭插件自己创建的临时加载页，再重载插件，最后由新版本刷新原来打开的相关 e621 页面。
已关闭、已跳转到其他页面的标签页会跳过；更新标记只消费一次，过期后失效，普通浏览器启动不会自动刷新。
